# Kransov Mods 🎮

**Студия скриптов для SA-MP**

# 🤔 Кто такие Kransov Mods?
Формально студия. По факту - один человек, который пишет скрипты для SA-MP.
**Marcus Kransov** - это разработчик (да, один), тестировщик (он же), техподдержка (тоже он) и автор всех трёх аккаунтов в авторстве (Marcus, Jonathan, Michael).
Студия создана ради рофла и официозности. Но скрипты делаются всерьёз.

# 📦 Что мы делаем?
Пишем скрипты для SA-MP серверов. В основном для себя и для удобства, но раз уж написано - почему бы не поделиться?

**Скрипты студии:**
| Скрипт | Назначение | Сервер |
|--------|------------|--------|
| Auto-AD | Авто-подача объявлений | Advance-RP Chocolate |
| Gay Locator [ROFL] | Система слежки за Колей и Дардасом | Advance-RP Chocolate |

# 🚀 Как пользоваться?
1. Скачай `kransov-mods.luac`
2. Кинь в папку `moonloader`
3. В игре: `/kransov` или `/km`
4. Выбирай скрипт → "Установить"
5. Готово
